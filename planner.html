F-04 · COORDINATED BLOCK OPTIMIZER

Use each block
once, intelligently.

Create a weekly or monthly proposed block plan from real F‑01 tasks, F‑02 feasibility results, F‑03 priorities and COA-available windows. Compatible work is sequenced into shared windows to avoid repeat disruption.

What is enforced
  1. Matching section and F‑02 hour
  2. COA traffic/disconnection capacity
  3. Crew conflict and window duration

COA planning input

Paste actual COA availability windows, each with the associated timetable and goods-forecast references.

No sample windows
Each window needs: corridor_id, section_id, start_time, end_time, max_simultaneous_crews, traffic_block_available, traction_disconnection_available, timetable_reference, goods_forecast_reference, passenger_trains_affected, goods_trains_affected. All times must be inside the selected horizon.

Only tasks with complete F‑01 data, an eligible F‑02 assessment that covers a COA window hour, and an F‑03 priority evaluation are considered.
